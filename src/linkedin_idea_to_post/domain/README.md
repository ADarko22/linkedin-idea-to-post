# LinkedIn Idea to Post Domain

This directory contains the core domain logic for the LinkedIn Idea to Post application.

## Content

1. [post.py](post.py): Contains the `Post` class, which represents a LinkedIn post. It includes attributes such as
   title, content, and metadata. The timestamps used are in UTC format to ensure consistency across different time
   zones.
2. [post_text.py](post_text.py): Contains pure functions for extracting text from the textual content of a LinkedIn
   post. These functions are designed to be reusable and can be used in various parts of the application.
